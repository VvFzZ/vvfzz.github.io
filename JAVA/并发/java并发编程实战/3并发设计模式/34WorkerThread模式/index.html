线程死锁的场景

现象：应用每运行一段时间偶尔就会处于无响应的状态，监控数据看上去一切都正常，但是实际上已经不能正常工作。

两个线程全部都阻塞在 l2.await();没有空闲的线程执行L2阶段的任务了.
解决办法：不同阶段任务使用不同线程池

提交到相同线程池中的任务一定是相互独立的，否则就一定要慎重
