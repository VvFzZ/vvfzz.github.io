信号量模型

一个计数器，一个等待队列，三个方法（init、down、up）
计数器和等待队列对外是透明的，只能通过信号量模型提供的三个方法来访问它们

  • init
    设置计数器的初始值。
  • down
    计数器值减1，如果计数器的值小于0，则当前线程将被阻塞，否则继续执行。
  • up
    计数器值加1，如果计数器值小于或者等于0，则唤醒等待队列中的一个线程，并将其移除。
