一种轻量级的线程
协程是在用户态调度切换的成本更低,线程是在内核态中调度
协程比线程栈要小得多,协程栈的大小往往只有几K或者几十K，线程栈大小差不多有1M

线程同步意味着等待，线程等待是严重浪费。协程等待成本没那么高。
