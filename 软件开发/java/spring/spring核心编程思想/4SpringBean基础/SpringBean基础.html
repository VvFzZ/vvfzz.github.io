  • 定义

    • BeanDefination 元信息
      Bean的配置元信息：bean类名；bean行为配置（作用域，自动绑定模式，生命周期回调）；其他Bean引用（依赖或合作者）；配置设置（Properties）
      两种BeanDefinition实例化方式：BeanDefinitionBuilder、AbstractBeanDefinition(GenericBeanDefinition)

    • 命名
      xml：DefaultBeanNameGenerator
      注解：AnnotationBeanNameGenerator

    • 别名
      <alias name="user" alias="xiaomage-user"/>

  • 加载（注册）
    1. xml配置
    2. java注解
      • @Bean
      • @Componet
      • @Import
    3. JAVA API
      • 命名方式 BeanDefinitionRegistry#registerBeanDefinition(String,BeanDefinition)
      • 非命名方式 BeanDefinitionReaderUtils#registerWithGeneratedName(AbstractBeanDefinition,BeadefinitionRegistry)
      • AnnotatedBeanDefinitionReader#Register(Class…)

//JAVA API
public static void registerUserBeanDefinition(BeanDefinitionRegistry registry, String beanName){

    //GenericBeanDefinition genericBeanDefinition = new GenericBeanDefinition();
    //genericBeanDefinition.setBeanClass(User.class);
    //MutablePropertyValues propertyValues = new MutablePropertyValues();
    //propertyValues.add( "id", 1).add( "name","小马哥");
    //genericBeanDefinition.setPropertyValues(propertyValues);

    BeanDefinitionBuilder beanDefinitionBuilder = BeanDefinitionBuilder.genericBeanDefinition(User.class);
    beanDefinitionBuilder
        .addPropertyValue( name:"id",value:1L)
        .addPropertyValue( name:"name",value:"小马哥");
    //判断如果 beanName 参数存在时
    if(StringUtils.hasText(beanName)){
        // 注册 BeanDefinition
        registry.registerBeanDefinition(beanName, beanDefinitionBuilder.getBeanDefinition());
    } else {
        // 非命名 Bean 注册方法
        BeanDefinitionReaderUtils.registerWithGeneratedName(beanDefinitionBuilder.getBeanDefinition(),registry);
    }
}

    3. 通过Bean工厂方法（配置元信息：xml，API）
