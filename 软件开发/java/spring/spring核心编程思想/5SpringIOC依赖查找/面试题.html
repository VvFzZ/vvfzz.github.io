ObjectFactory 与 BeanFactory的区别

都提供依赖查找能力；
ObjectFactory本身不具备以来查找能力，依靠BeanFactory提供，且仅提供一个或一种类型Bean依赖查找
BeanFactory提供单个，集合，层次性多种以来查找方式

ObjectFactory实例：org.springframework.beans.factory.config.ObjectFactoryCreatingFactoryBean

BeanFactory.getBean是否线程安全

安全,DefaultListableBeanFactory实现会加锁
