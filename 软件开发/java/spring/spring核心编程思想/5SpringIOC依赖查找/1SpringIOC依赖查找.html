  • 根据类型+名称查找
public class ObiectProviderDemo {
    public static void main(String[]args){
        // 创建 BeanFactory 容器
        AnnotationConfigApplicationContext applicationContext = new AnnotationConfigApplicationContext();
        //将当前类 ObjectProviderDemo 作为配置类(Configuration.Class)
        applicationContext.register(ObjectProviderDemo.class);// 启动应用上下文
        applicationContext.refresh();
        // 依赖查找集合对象
        lookupByObjectProvider(applicationContext);
        // 关闭应用上下文
        applicationContext.close();
    }

    @Bean
    public String helloWorld(){ 
        //方法名就是 Bean 名称="helloWorld"
        return "Hello,World";
    }

    private static void lookupByObjectProvider(AnnotationConfigApplicationContext applicationcontext) {
        ObiectProvider<String> objectProvider = applicationContext.getBeanProvider(String.class);
        System.out.println(objectProvider.getObject());
    }
    
}

安全依赖查找

不安全原因会爆异常：NoSuchBeanDefinitionException 或 BeanNotOfRequiredTypeException
单一类型查找

  • BeanFactory#getBean 不安全
  • ObjectFactory#getObject 不安全
  • ObjectProvider#getlfAvailable 安全 （延迟加载推荐使用）

集合类型查找

  • ListableBeanFactory#getBeansOfType 安全
  • ObjectProvider#stream 安全

ObjectProvider支持单一和集合类型查找，推荐使用
